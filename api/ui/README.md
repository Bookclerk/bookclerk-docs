# Bookclerk UI

Vite + React + TypeScript library GUI (shadcn-style components, Bookclerk brand).

```bash
npm ci
npm run dev      # proxied to bookclerkd on :8787
npm run build    # writes dist/ for bookclerkd ServeDir
```

See [docs/gui.md](../../gui.md).
