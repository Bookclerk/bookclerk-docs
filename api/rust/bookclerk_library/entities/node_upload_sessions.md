Row shape for one upload.

**Fields**

- `upload_id`: Upload id (hyphenated UUID).
- `token_hash`: `hash_token` of the bearer token; the token itself is never stored.
- `node_id`: Host node the upload was granted to.
- `job_id`: Acquire job the upload belongs to.
- `lease_generation`: Lease generation the grant was made under; the upload is accepted
  only while it is the job's live fence for this node.
- `receiving_node_id`: Owner node that streams the files to its destinations.
- `book_uuid`: Library id of the title.
- `primary_key`: Storage key of the title's primary audio file.
- `manifest_json`: The declared files and PDF key (JSON object `{files, pdfKey}`, each
  file `{key, size, sha256, content_type}`).
- `received_json`: Indexes of the files written to every destination (JSON list).
- `state`: `open`, `committed` or `aborted`.
- `created_at`: RFC 3339 grant time.
- `expires_at`: RFC 3339 time after which the token is refused.
- `committed_at`: RFC 3339 commit time.
