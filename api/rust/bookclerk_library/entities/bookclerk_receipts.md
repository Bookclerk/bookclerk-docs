Row shape for this table (`DeriveEntityModel`).

**Fields**

- `operation_id`: Caller-chosen idempotency key (`operationId`).
- `operation_kind`: Named operation tag (`deleteUser`, `takeOidcRpState`, …).
- `request_hash`: SHA-256 hex digest of the canonical `operation` JSON.
- `status`: Application status stored with the first commit.
- `payload`: JSON payload when the first commit produced one.
- `created_at`: RFC 3339 timestamp when the receipt was first written.
- `expires_at`: RFC 3339 expiry; bounded cleanup deletes older rows.
- `consume_key`: Unique consume-once token (`oidc:<hash>`, `webauthn:<id>:<kind>`).
