```rust
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Surrogate primary key assigned by the database.
- `client_id`: Registered OIDC client_id.
- `client_secret_hash`: Hash of the OIDC client secret (plaintext never stored).
- `redirect_uris_json`: JSON array of allowed OAuth redirect URIs.
- `name`: Human-readable or logical name for this row.
- `created_at`: RFC 3339 timestamp when the row was inserted.
- `issue_refresh_token`: When true, token responses include a refresh token.
- `allowed_scopes_json`: JSON array of scopes this client may be granted.
- `enabled`: When non-zero, authorize and token endpoints accept this client.
- `plugin_id`: Plugin identity that owns this client; `None` for operator-created
  clients. Product guests store the canonical PluginKey (alias-era
  rows are rewritten on the next heartbeat).
