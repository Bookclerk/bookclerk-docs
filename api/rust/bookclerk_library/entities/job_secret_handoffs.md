# bookclerk_library::entities::job_secret_handoffs

SeaORM entity for `job_secret_handoffs`: which store-account secrets a
Host was handed with a job, per lease generation.

Recorded when the claim hands the secrets over and read when the Host
writes a refreshed token back, so a write-back is accepted only for a
secret that went out under that exact fence. Carries no secret material.

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `job_id`: Job the secret was handed with (`jobs.id`).
- `lease_generation`: Lease generation of the claim that handed it.
- `kind`: Secret kind (`source_auth`, ...).
- `provider`: Plugin key that owns the secret.
- `account_id`: Store account id.
- `name`: Logical secret name.
- `node_id`: Node the secret was handed to.
- `handed_at`: RFC 3339 time of the handoff.
