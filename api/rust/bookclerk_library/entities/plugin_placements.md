Row shape for this table (`DeriveEntityModel`).

**Fields**

- `plugin_instance_id`: Placed instance.
- `replicas`: Hosts that should run the instance; empty means every host that
  qualifies and has room.
- `constraints_json`: JSON array of label constraints every chosen host must satisfy.
- `revision`: Compare-and-swap revision of the operator's intent.
- `updated_at`: RFC 3339 time of the last intent write.
- `updated_by`: Audit identity of the last intent writer.
- `placed`: Replicas the last scheduler pass placed.
- `detail`: Why the last pass placed fewer than `replicas`; empty when satisfied.
- `scheduled_at`: RFC 3339 time of the last scheduler pass that changed the status.
