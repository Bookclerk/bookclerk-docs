### Model

```rust
pub struct Model {
    pub scope_type: String,
    pub scope_id: String,
    pub namespace: String,
    pub schema_version: i64,
    pub revision: i64,
    pub document_json: String,
    pub updated_at: String,
    pub updated_by: String,
    pub write_operation_id: String,
}
```

Row shape for a scoped configuration document.

**Fields**

- `scope_type`: Scope kind (`cluster` or `host`).
- `scope_id`: Scope instance (`singleton` or a host id).
- `namespace`: Typed domain name (`core.events`, `node.runtime`).
- `schema_version`: Domain schema version understood by this binary.
- `revision`: Monotonic compare-and-swap revision. Starts at 1.
- `document_json`: JSON body of the typed domain document.
- `updated_at`: RFC 3339 timestamp of the last committed replacement.
- `updated_by`: Audit identity of the last writer.
- `write_operation_id`: Operation id of the write that produced the current revision.
