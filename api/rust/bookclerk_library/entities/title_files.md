# bookclerk_library::entities::title_files

SeaORM entity for `title_files`: every file key a title's acquire or
host upload wrote, per output destination (H-4 design, section 6).
Written by the acquire pipeline ([`crate::LibraryStore::record_title_file`](../index.md#librarystorerecord_title_file))
and by `control_plane::uploads`, which refuses an upload a key another
title holds and deletes an aborted upload's copy only while the key is
still its own.

## Structs

### Model

```rust
pub struct Model {
    pub destination: String,
    pub storage_key: String,
    pub book_uuid: String,
    pub writer: String,
    pub written_at: String,
}
```

Row shape for one recorded file key.

**Fields**

- `destination`: Output destination id (`local`, `s3`).
- `storage_key`: Storage key on that destination.
- `book_uuid`: Library id (`books.uuid`) of the title the file belongs to.
- `writer`: The host upload id that claimed the key last, or
  [`crate::store::ACQUIRE_WRITER`](../index.md#acquire_writer) for an acquire run on this node.
- `written_at`: RFC 3339 time of the latest claim.
