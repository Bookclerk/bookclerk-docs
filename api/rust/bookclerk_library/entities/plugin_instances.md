### Model

```rust
pub struct Model {
    pub plugin_instance_id: String,
    pub plugin_key: String,
    pub display_name: String,
    pub created_at: String,
    pub created_by: String,
    pub owner_node_id: Option<String>,
}
```

Row shape for one plugin instance.

The id is not a plugin key, alias, capability, or host id.
`plugin_key` is an immutable reference to the package this instance installs.

**Fields**

- `plugin_instance_id`: Stable instance id (hyphenated UUID). Minted once at create.
- `plugin_key`: Canonical plugin key of the package this instance runs.
- `display_name`: Operator-facing name; empty for the default instance.
- `created_at`: RFC 3339 timestamp of the insert.
- `created_by`: Audit identity of the creator.
- `owner_node_id`: The node that owns this instance (a node-local output, H-2): it is
  deployed only there. `None` for cluster instances.
