### Model

```rust
pub struct Model {
    pub owner_cluster_id: String,
    pub owner_origin: String,
    pub remote_node_id: String,
    pub spki_pin: Option<String>,
    pub state: String,
    pub enrolled_at: String,
    pub share_books: i64,
    pub include_branches: i64,
    pub ancestry_json: String,
}
```

Row shape for one link from this install to an owner cluster.

**Fields**

- `owner_cluster_id`: Owner cluster id returned by enrollment.
- `owner_origin`: Owner origin (`https://owner.example`).
- `remote_node_id`: Node id the owner minted for this install.
- `spki_pin`: SPKI pin from the enrollment link, when it carried one.
- `state`: `active`, `revoked`, or `left`.
- `enrolled_at`: RFC 3339 enrollment time.
- `share_books`: "Share this branch's books with *library*" (1 = on, the default).
- `include_branches`: "Include books from my own branches" (1 = on, the default).
- `ancestry_json`: The owner library's ancestry (JSON list of cluster ids, the owner's
  own first), as it last reported it.
