## bookclerk_library::entities::nodes::Model

*Struct*

Row shape for one Bookclerk node in the cluster.

**Fields:**
- `node_id: String` - Stable node identifier. Not derived from hostname.
- `cluster_id: String` - Cluster this node enrolled into.
- `created_at: String` - RFC 3339 timestamp of the first successful registration.
- `incarnation: String` - Latest process incarnation observed for this node.
- `heartbeat_at: String` - RFC 3339 timestamp of the latest heartbeat.
- `software_version: String` - Bookclerk version string reported by the latest heartbeat.
- `schema_state: String` - Schema state display reported by the latest heartbeat.
- `compatible: i64` - `1` when the reporting binary accepted the library schema.
- `logical_cpus: Option<i64>` - `available_parallelism`, empty when the probe failed.
- `cpu_max_quota_us: Option<i64>` - Process cgroup `cpu.max` quota in microseconds. Empty when unlimited or missing.
- `cpu_max_period_us: Option<i64>` - Process cgroup `cpu.max` period in microseconds. Empty when unlimited or missing.
- `memory_max_bytes: Option<i64>` - Process cgroup `memory.max` in bytes. Empty when unlimited or missing.
- `memory_current_bytes: Option<i64>` - Process cgroup `memory.current` in bytes.
- `memory_anon_bytes: Option<i64>` - Process cgroup `memory.stat` field `anon`.
- `files_dir_free_bytes: Option<i64>` - Free bytes on the filesystem that holds `$BOOKCLERK_FILES_DIR`.
- `scratch_bytes: Option<i64>` - Byte size of the acquire scratch tree under the download cache.
- `target: String` - Bookclerk artifact target of the reporting binary (`linux-x64-gnu`, …).
- `labels_json: String` - JSON array of operator-assigned placement labels.
- `kind: String` - `owner` (shares the database and `master.key`) or `host` (its own
- `owner_user_id: Option<i64>` - User who owns this node and may administer it, when one is assigned.
- `share_books: Option<i64>` - For a branch (host node): "Share this branch's books with *library*"
- `include_branches: Option<i64>` - For a branch: "Include books from my own branches", as reported.
- `catalog_fence: i64` - The branch's catalog fence; `catalog.*` frames under another are
- `catalog_cursor: String` - Cursor the branch's catalog sync resumes after.
- `catalog_pass_started_at: Option<String>` - RFC 3339 start of the branch's current full catalog pass.
- `catalog_synced_at: Option<String>` - RFC 3339 time of the branch's last accepted catalog batch.
- `catalog_full_pass_at: Option<String>` - RFC 3339 end of the branch's last completed full catalog pass.
