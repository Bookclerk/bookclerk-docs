Row shape for one Bookclerk node in the cluster.

**Fields**

- `node_id`: Stable node identifier. Not derived from hostname.
- `cluster_id`: Cluster this node enrolled into.
- `created_at`: RFC 3339 timestamp of the first successful registration.
- `incarnation`: Latest process incarnation observed for this node.
- `heartbeat_at`: RFC 3339 timestamp of the latest heartbeat.
- `software_version`: Bookclerk version string reported by the latest heartbeat.
- `schema_state`: Schema state display reported by the latest heartbeat.
- `compatible`: `1` when the reporting binary accepted the library schema.
- `logical_cpus`: `available_parallelism`, empty when the probe failed.
- `cpu_max_quota_us`: Process cgroup `cpu.max` quota in microseconds. Empty when unlimited or missing.
- `cpu_max_period_us`: Process cgroup `cpu.max` period in microseconds. Empty when unlimited or missing.
- `memory_max_bytes`: Process cgroup `memory.max` in bytes. Empty when unlimited or missing.
- `memory_current_bytes`: Process cgroup `memory.current` in bytes.
- `memory_anon_bytes`: Process cgroup `memory.stat` field `anon`.
- `files_dir_free_bytes`: Free bytes on the filesystem that holds `$BOOKCLERK_FILES_DIR`.
- `scratch_bytes`: Byte size of the acquire scratch tree under the download cache.
- `target`: Bookclerk artifact target of the reporting binary (`linux-x64-gnu`, …).
- `labels_json`: JSON array of operator-assigned placement labels.
- `kind`: `owner` (shares the database and `master.key`) or `host` (its own
  database, enrolled to contribute).
- `owner_user_id`: User who owns this node and may administer it, when one is assigned.
- `share_books`: For a branch (host node): "Share this branch's books with *library*"
  as the branch last reported it (`catalog.begin`); empty until then.
- `include_branches`: For a branch: "Include books from my own branches", as reported.
- `catalog_fence`: The branch's catalog fence; `catalog.*` frames under another are
  lost.
- `catalog_cursor`: Cursor the branch's catalog sync resumes after.
- `catalog_pass_started_at`: RFC 3339 start of the branch's current full catalog pass.
- `catalog_synced_at`: RFC 3339 time of the branch's last accepted catalog batch.
- `catalog_full_pass_at`: RFC 3339 end of the branch's last completed full catalog pass.
