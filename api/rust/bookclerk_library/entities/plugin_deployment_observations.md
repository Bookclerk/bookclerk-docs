## bookclerk_library::entities::plugin_deployment_observations::Model

*Struct*

Row shape for one host's observation of a deployment.

Written only by the reconciler on that host. A desired row does not create this row.

**Fields:**
- `deployment_id: String` - Deployment this observation describes.
- `node_id: String` - Host that recorded the observation. Matches the deployment target when local.
- `incarnation: String` - Process incarnation that recorded the row.
- `status: String` - `materialized`, `running`, `healthy`, `error`, or `retired`.
- `detail: String` - Bounded detail. Empty when the status is `healthy`.
- `applied_config_revision: Option<i64>` - Config revision applied by the last spawn. Null until a spawn applies one.
- `observed_at: String` - RFC 3339 timestamp of this observation.
- `reserved_memory_bytes: Option<i64>` - Memory ceiling of the running guest (its grant after `[plugins.jail]`).
- `reserved_cpu_millicores: Option<i64>` - CPU ceiling of the running guest, in millicores.
