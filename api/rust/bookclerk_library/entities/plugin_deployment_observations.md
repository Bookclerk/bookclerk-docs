```rust
pub struct Model {

    pub reserved_cpu_millicores: Option<i64>,
}
```

Row shape for one host's observation of a deployment.

Written only by the reconciler on that host. A desired row does not create this row.

**Fields**

- `deployment_id`: Deployment this observation describes.
- `node_id`: Host that recorded the observation. Matches the deployment target when local.
- `incarnation`: Process incarnation that recorded the row.
- `status`: `materialized`, `running`, `healthy`, `error`, or `retired`.
- `detail`: Bounded detail. Empty when the status is `healthy`.
- `applied_config_revision`: Config revision applied by the last spawn. Null until a spawn applies one.
- `observed_at`: RFC 3339 timestamp of this observation.
- `reserved_memory_bytes`: Memory ceiling of the running guest (its grant after `[plugins.jail]`).
- `reserved_cpu_millicores`: CPU ceiling of the running guest, in millicores.
