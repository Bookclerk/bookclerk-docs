```rust
    pub updated_at: String,

```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Expression id (a random UUID).
- `work_id`: The work it realises.
- `kind`: How it realises the work: `narration`, `text`, `translation`, `dramatisation` or `podcast_audio`.
- `language`: Lower-cased language code; `None` when unknown.
- `abridgement`: `unknown`, `unabridged` or `abridged`.
- `credit_key`: Sorted, cleaned names of its narrator, translator, host and cast credits.
- `created_at`: RFC 3339 timestamp when the row was inserted.
- `updated_at`: RFC 3339 timestamp when the row was last modified.
