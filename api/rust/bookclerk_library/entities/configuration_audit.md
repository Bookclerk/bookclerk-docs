### Model

```rust
pub struct Model {
    pub id: i64,
    pub scope_type: String,

    pub schema_version: i64,
    pub revision: i64,
    pub actor: String,
    pub recorded_at: String,
}
```

Row shape for one committed configuration change.

**Fields**

- `id`: Surrogate primary key.
- `scope_type`: Scope kind copied from the document at commit time.
- `scope_id`: Scope instance copied from the document at commit time.
- `namespace`: Domain namespace copied from the document at commit time.
- `schema_version`: Domain schema version after the commit.
- `revision`: Document revision after the commit.
- `actor`: Audit identity of the writer.
- `recorded_at`: RFC 3339 timestamp of the commit.
