Row shape for this table (`DeriveEntityModel`).

**Fields**

- `edition_id`: The edition it names.
- `scheme`: Identifier scheme (`isbn`, `asin`, `openlibrary_edition`).
- `value`: Normalised identifier value.
- `marketplace`: Lower-cased marketplace for a scoped scheme (ASIN); empty otherwise.
- `strength`: `strong` (names one edition) or `weak` (shared, only proposes a match).
- `strong_key`: Unique key of a strong identifier; `None` for a weak one.
- `created_at`: RFC 3339 timestamp when the row was inserted.
