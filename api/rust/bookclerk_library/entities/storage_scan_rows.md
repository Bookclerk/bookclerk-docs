# bookclerk_library::entities::storage_scan_rows

SeaORM entity for paged storage-scan rows.

Object and identity hits live here so a scan does not retain the inventory
in process memory. `kind` is `object` or `identity`.

## Structs

### Model

```rust
pub struct Model {
    pub scan_id: String,
    pub kind: String,
    pub identity: String,
    pub object_key: String,
    pub size: i64,
    pub media_rank: i64,
    pub is_audio: i64,
    pub claimed: i64,
}
```

One durable scan row.

**Fields**

- `scan_id`: Scan generation id.
- `kind`: `object` or `identity`.
- `identity`: Uppercase ASIN/ISBN for identity rows; empty for object rows.
- `object_key`: Storage key.
- `size`: Object size in bytes.
- `media_rank`: Lower is a better packaged format.
- `is_audio`: 1 when the key is acquired audio.
- `claimed`: 1 after a library row claims the object.
