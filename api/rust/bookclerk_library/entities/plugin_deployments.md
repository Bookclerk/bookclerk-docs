## bookclerk_library::entities::plugin_deployments::Model

*Struct*

Row shape for one desired deployment of a plugin instance onto a host.

This is desired state. It is not evidence that the host installed the package.

**Fields:**
- `deployment_id: String` - Deployment id (hyphenated UUID).
- `plugin_instance_id: String` - Instance this deployment runs.
- `node_id: String` - Host that should install and run the instance.
- `desired: String` - Desired presence: `present` or `absent`.
- `revision: i64` - Monotonic compare-and-swap revision. Starts at 1.
- `updated_at: String` - RFC 3339 timestamp of the last desired-state write.
- `updated_by: String` - Audit identity of the last desired-state writer.
