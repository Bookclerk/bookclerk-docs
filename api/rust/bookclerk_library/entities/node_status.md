Row shape for this table (`DeriveEntityModel`).

**Fields**

- `node_id`: Reporting node.
- `incarnation`: Daemon process incarnation.
- `started_at`: RFC 3339 time the daemon process started.
- `heartbeat_at`: RFC 3339 time of this heartbeat.
- `heartbeat_ms`: Same time in Unix milliseconds (liveness arithmetic).
- `interval_ms`: Heartbeat interval the daemon promised, in milliseconds.
- `cpu_millicores`: Detected CPU capacity in millicores (machine or cgroup, whichever is tighter).
- `memory_bytes`: Detected memory in bytes; empty when unknown.
- `cpu_budget_millicores`: CPU the scheduler may commit here, in millicores.
- `memory_budget_bytes`: Memory the scheduler may commit here; empty when memory is unknown.
- `schedulable`: `1` unless an operator drained the node.
- `cpu_used_millicores`: Measured CPU in use, in millicores; empty until two samples exist.
- `memory_available_bytes`: Measured memory available to new work.
- `files_dir_free_bytes`: Free bytes on the files directory's filesystem.
- `reserved_cpu_millicores`: Sum of running guests' CPU ceilings, in millicores.
- `reserved_memory_bytes`: Sum of running guests' memory ceilings.
- `running_guests`: Guests running on the node.
- `availability_ppm`: Recent online fraction in parts per million.
- `online_since_ms`: Unix milliseconds the current unbroken online stretch began.
