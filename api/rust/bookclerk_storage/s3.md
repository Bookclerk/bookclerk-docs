## bookclerk_storage::s3::S3Credentials

*Struct*

Static AWS-style credentials for the S3 destination.

These come from the instance's sealed secrets; without them the SDK
default provider chain applies inside the guest.

- `secret_access_key: String` - AWS secret access key (redacted in [`Debug`](https://doc.rust-lang.org/stable/core/fmt/macros/derive.Debug.html); never logged).

## bookclerk_storage::s3::S3Settings

*Struct*

Connection settings for one S3 / MinIO destination.

The `s3` destination plugin declares these as `[[settings]]`; the host
resolves them from the plugin instance document and hands them to the
guest as its open context.

**Fields:**
- `bucket: String` - Destination bucket name (required).
- `region: String` - AWS region id (also used by MinIO path-style clients).
- `endpoint: Option<String>` - Optional custom endpoint (MinIO, LocalStack, …).
- `force_path_style: bool` - Force path-style addressing (typical for MinIO).

**Traits:** Eq
