# bookclerk_libav::fixtures

Small audio files in every format this crate decodes, for tests here
and in the crates that use it.

The WMA and AC-3 files are half-second 440 Hz tones made with FFmpeg's
own encoders (bit-exact flags, no metadata). AMR has no encoder in the
build, so its files are assembled here: frames of the lowest bit rate
filled with pseudo-random bits, which any AMR decoder turns into half a
second of noise; the 3GP file carries those same frames.

| Item | Kind | Summary |
| --- | --- | --- |
| [`amr_nb`](#amr_nb) | function | A raw AMR-NB file (`#!AMR`): 25 frames of 4.75 kbit/s, 0.5 s at 8 kHz. |
| [`amr_wb`](#amr_wb) | function | A raw AMR-WB file (`#!AMR-WB`): 25 frames of 6.60 kbit/s, 0.5 s at 16 kHz. |
| [`WMAV2`](#wmav2) | constant | WMA 2 (stereo, 44.1 kHz) in ASF. |
| [`WMAV1`](#wmav1) | constant | WMA 1 (mono, 44.1 kHz) in ASF. |
| [`AC3`](#ac3) | constant | A raw AC-3 stream (stereo, 48 kHz). |
| [`EAC3`](#eac3) | constant | A raw E-AC-3 stream (stereo, 48 kHz). |
| [`EAC3_MP4`](#eac3_mp4) | constant | E-AC-3 (stereo, 48 kHz) in an MP4 (`ec-3` sample entry). |
| [`AMR_WB_3GP`](#amr_wb_3gp) | constant | AMR-WB in a 3GP file: the frames of `amr_wb` remuxed (FFmpeg, stream copy), so Symphonia's MP4 reader finds a track it has no decoder for. |
