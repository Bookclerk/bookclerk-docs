### Model

```rust
pub struct Model {
    pub id: i64,
    pub target_kind: String,
    pub target_id: String,
    pub model: String,
    pub revision: String,
    pub packs: String,
    pub dims: i64,
    pub vector: Vec<u8>,
    pub text_hash: String,
    pub created_at: String,
    pub updated_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Surrogate primary key assigned by the database.
- `target_kind`: What was embedded: `work` (a `works.id`) or `text` (a text shared
  by every candidate that has it).
- `target_id`: Id of the embedded target within `target_kind`: the work id, or the
  SHA-256 hex of the text.
- `model`: What made `vector`: `@<plugin id>/<model id>`, or `local-hash-v1`
  for the stand-in.
- `revision`: The model's digest of everything that decides its output; empty for
  the stand-in. Vectors are compared only inside one (`model`,
  `revision`).
- `packs`: BCP 47 tags of the languages the model was loaded for, joined by
  `,`; empty when it has no language packs.
- `dims`: Dimensionality of the stored embedding vector.
- `vector`: Raw embedding bytes (little-endian f32 sequence).
- `text_hash`: Hash of the text that was embedded (skip re-embed when unchanged).
- `created_at`: RFC 3339 timestamp when the row was inserted.
- `updated_at`: RFC 3339 timestamp when the vector was written or, for a `text`
  row, last used.
