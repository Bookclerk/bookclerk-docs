### Model

```rust
pub struct Model {
    pub listing_id: String,
    pub audience: String,
    pub price_cents: Option<i64>,
    pub price_label: Option<String>,
    pub currency: Option<String>,
    pub observed_at: String,
}
```

One price a store asks for one listing, for one audience (`DeriveEntityModel`).

**Fields**

- `listing_id`: The `store_listings` row priced.
- `audience`: `non_member` (no account at the store) or `member`.
- `price_cents`: Price in minor units of [`Self::currency`](#model), when the store gave one.
- `price_label`: The store's formatted price (`$14.95`), when it gave one.
- `currency`: ISO 4217 currency code.
- `observed_at`: RFC 3339 time the store quoted it.
