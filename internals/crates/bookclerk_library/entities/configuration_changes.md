### Model

```rust
pub struct Model {
    pub id: i64,
    pub scope_type: String,
    pub scope_id: String,
    pub namespace: String,
    pub revision: i64,
    pub committed_at: String,
}
```

Row shape for one committed configuration notice.

Hosts reconcile by reading document revisions. This table is the
transactional notice of that commit; plugin event delivery is not a
broadcast to every host.

**Fields**

- `id`: Surrogate primary key.
- `scope_type`: Scope kind of the committed document.
- `scope_id`: Scope instance of the committed document.
- `namespace`: Domain namespace of the committed document.
- `revision`: Document revision after the commit.
- `committed_at`: RFC 3339 timestamp of the commit.
