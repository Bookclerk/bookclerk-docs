### Model

```rust
pub struct Model {
    pub owner_cluster_id: String,
    pub store: String,
    pub marketplace: String,

    pub work_ref: String,
    pub local_work_id: Option<String>,
    pub parts_version: String,
    pub seen_at: String,
}
```

One edition a library holds for this install's person.

**Fields**

- `owner_cluster_id`: The library (owner cluster id) that holds it.
- `store`: The store's plain id (`audible`, `libro`, ...).
- `marketplace`: Lower-cased store marketplace; empty when the store has none.
- `product_id`: The store's product id.
- `work_ref`: The library's own key grouping its editions of one work; only
  compared within that library.
- `local_work_id`: The work of this install's library the identifiers reach, when
  exactly one does.
- `parts_version`: The `window_book_parts` version holding this edition's details.
- `seen_at`: RFC 3339 stamp of the read that last named this edition.
