Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Listing id (a random UUID).
- `plugin_key`: Provenance-qualified PluginKey of the storefront.
- `marketplace`: Lower-cased marketplace.
- `product_id`: The store's own product id.
- `edition_id`: The edition it sells.
- `title`: Title as the store lists it.
- `categories`: Store category labels when reported.
- `subtitle`: Subtitle as the store lists it.
- `authors`: Authors as the store credits them, comma-separated, for display.
  Work identity comes from the resolver's credits, never from this.
- `narrators`: Narrators as the store credits them, comma-separated, for display.
- `series`: Series name as the store lists it.
- `series_index`: Position in that series as the store writes it (`1`, `2.5`).
- `description`: The store's synopsis, kept whole (may contain HTML).
- `publisher`: Publisher or imprint as the store lists it.
- `published_at`: Publication date as the store reports it.
- `length_minutes`: Runtime in whole minutes.
- `language`: Language code the store reports (`en`, `de`).
- `cover_url`: HTTPS cover image URL from the store.
- `url`: The store's product page URL.
- `rating_overall`: The store's community rating (0 to 5).
- `rating_count`: How many ratings back [`Self::rating_overall`](#model).
- `is_abridged`: `1` when the store marks it abridged, `0` unabridged, null unknown.
- `observed_at`: RFC 3339 time of the latest scan or catalog answer that reported it.
- `created_at`: RFC 3339 timestamp when the row was inserted.
- `updated_at`: RFC 3339 timestamp when the row was last modified.
