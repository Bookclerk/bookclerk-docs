**Fields**

- `id`: Listing id (a random UUID).
- `plugin_key`: Provenance-qualified PluginKey of the storefront.
- `marketplace`: Lower-cased marketplace.
- `product_id`: The store's own product id.
- `edition_id`: The edition it sells.
- `title`: Title as the store lists it.
- `categories`: Store category labels when reported.
- `observed_at`: RFC 3339 time of the latest scan that reported it.
- `created_at`: RFC 3339 timestamp when the row was inserted.
- `updated_at`: RFC 3339 timestamp when the row was last modified.
