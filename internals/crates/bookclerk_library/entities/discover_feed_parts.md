### Model

```rust
pub struct Model {
    pub subject_key: String,
    pub version: String,
    pub seq: i64,
    pub body: String,
}
```

One piece of a stored Discover feed too wide for one statement or cell
(`DeriveEntityModel`).

**Fields**

- `subject_key`: Discover subject the feed belongs to (`discover_feeds.subject_key`).
- `version`: The write this piece belongs to; `discover_feeds.feed_version` names the one to read.
- `seq`: The piece's place in the feed, from 0.
- `body`: The piece of the feed's JSON text, cut on a character boundary.
