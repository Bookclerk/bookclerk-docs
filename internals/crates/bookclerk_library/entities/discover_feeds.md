### Model

```rust
pub struct Model {
    pub id: i64,
    pub subject_key: String,
    pub feed_json: String,
    pub seed_scope: String,
    pub candidates_fetched_at: Option<String>,
    pub computed_at: String,
}
```

The stored Discover shelves of one subject (`DeriveEntityModel`).

**Fields**

- `id`: Surrogate primary key assigned by the database.
- `subject_key`: Discover subject (`operator`, `user:<id>`, `portal:<id>`); one feed each.
- `feed_json`: The ranked feed as JSON (`bookclerk_discover::DiscoverFeed`), before hidden shelves are removed.
- `seed_scope`: Which seeds the feed was ranked from: `own` or `household`.
- `candidates_fetched_at`: RFC 3339 timestamp of the newest candidate fetch the feed used, when any.
- `computed_at`: RFC 3339 timestamp when the feed was ranked.
