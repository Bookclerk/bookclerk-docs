# bookclerk_library::entities::work_tags

SeaORM entity for `work_tags`: library tags on a top-level work, one
row per tag and source.

An Administrator's tags are written by
[`crate::LibraryStore::set_work_tags`](../README.md#librarystoreset_work_tags); the page index refresh copies
every tag of a work into `library_work_facets` as facet `tag`, which the
Library filter and patron scopes match.

### Model

```rust
pub struct Model {
    pub work_id: String,
    pub source: String,
    pub key: String,
    pub value: String,
    pub created_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `work_id`: The top-level work (`works.id`).
- `source`: Where the tag came from: `admin` (set in Bookclerk) or `sidecar`
  (read from a metadata file beside the book).
- `key`: The tag trimmed and lower-cased, which a filter or scope matches.
- `value`: The tag as it was written.
- `created_at`: When the tag was added (RFC 3339).
