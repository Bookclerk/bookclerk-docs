# bookclerk_library::entities::edition_copies

SeaORM entity for `edition_copies`: each edition's copy at each output
destination and where it stands (storage destinations ADR,
`docs/adr/storage-destinations.md`, decision 3).

Written by the acquire pipeline once each destination's write ends
([`crate::LibraryStore::set_copy_stored`](../README.md#librarystoreset_copy_stored),
[`crate::LibraryStore::set_copy_pending`](../README.md#librarystoreset_copy_pending)) and by a host upload's commit
on the owner; read by acquire candidate selection, which visits an
acquired edition again while a destination that takes it lacks a stored
copy.


Row shape for this table (`DeriveEntityModel`).

**Fields**

- `edition_id`: The edition (`editions.id`).
- `destination`: The destination's plugin instance id.
- `state`: Where the copy stands (`CopyState::as_str`): `stored`, `pending`, `missing` or
  `failed`.
- `storage_key`: The edition's primary audio key on this destination; set once
  stored, and kept from an earlier stored copy while a later write is
  retried.
- `attempts`: Failed writes since the copy was last stored (0 once stored).
- `next_attempt_at`: RFC 3339 time the next background attempt is due; `None` unless
  pending.
- `last_error`: The last write failure, for operators; `None` once stored.
- `updated_at`: RFC 3339 timestamp when the row was last modified.
