# bookclerk_library::entities::edition_acquisitions

SeaORM entity for `edition_acquisitions`: each edition's acquire state.

Files belong to editions, so one acquire serves every library title
(`books` row) of the edition. Written beside the title's own status by
[`crate::LibraryStore::set_acquire_status`](../README.md#librarystoreset_acquire_status); an edition with no row is
not acquired.

### Model

```rust
pub struct Model {
    pub edition_id: String,
    pub status: String,
    pub storage_key: Option<String>,
    pub error_message: Option<String>,
    pub title_uuid: String,
    pub updated_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `edition_id`: The edition (`editions.id`).
- `status`: Acquire state (`AcquireStatus::as_str`): `not_acquired`, `queued`,
  `downloading`, `acquired` or `error`.
- `storage_key`: Primary destination key of the edition's audio once acquired.
- `error_message`: Last acquire failure message for operators.
- `title_uuid`: The library title (`books.uuid`) whose write set this row; while it
  stays in the library, only its writes change an acquired edition.
- `updated_at`: RFC 3339 timestamp when the row was last modified.
