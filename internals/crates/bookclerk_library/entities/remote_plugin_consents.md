Row shape for one owner plugin of one owner cluster.

**Fields**

- `owner_cluster_id`: Owner cluster id the plugin belongs to.
- `plugin_key`: Canonical plugin key.
- `requested_version`: Version the owner currently deploys here.
- `requested_grant_json`: The owner's approved grant (JSON) for that version.
- `requested_artifact_url`: URL of the archive the owner deploys to this host (the artifact for
  this host's target).
- `requested_artifact_sha256`: SHA-256 of that archive, as the owner states it.
- `requested_artifact_payload_sha256`: Payload-root digest of the tree that archive unpacks to, as the
  owner states it (the `plugins/.versions/<digest>` cache key).
- `version`: Version this install's operator approved; `None` until approved.
- `approved_request_json`: The owner's grant as it stood when the operator approved; a later
  request outside it needs approval again.
- `approved_artifact_url`: The archive URL as it stood when the operator approved; another URL
  needs approval again.
- `approved_artifact_sha256`: The archive SHA-256 as it stood when the operator approved.
- `approved_artifact_payload_sha256`: The payload-root digest as it stood when the operator approved.
- `grant_json`: The grant this install's operator consented to (JSON), never wider
  than `approved_request_json`.
- `approved_at`: RFC 3339 approval time.
- `approved_by`: Audit identity of the approver (`platform` for an automatic
  approval of a bundled platform plugin).
- `revoked_at`: RFC 3339 time this install's operator revoked the approval; while
  set, no automatic approval is given (only an operator approval
  clears it).
- `updated_at`: RFC 3339 time of the last write.
