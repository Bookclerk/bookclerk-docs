# bookclerk_library::entities::metadata_claims

SeaORM entity for `metadata_claims`: one source's value for one field
of one subject (`docs/adr/metadata-claims-and-file-sync.md`). Chapters
of an edition are the only field so far (`store::chapters`).

Row shape for one claim.

**Fields**

- `subject_kind`: What the claim is about: `edition`.
- `subject_id`: The subject's id (`editions.id`).
- `field`: The field: `chapters`.
- `source_kind`: The kind of source ([`crate::ChapterSourceKind`](../README.md#chaptersourcekind) spelling).
- `source_id`: Which source of that kind: a plugin key for a provider or a store,
  empty for a person's edit and for Bookclerk's own processing.
- `locale`: BCP 47 language of the value; empty when unknown or not applicable.
- `quality`: Where a machine source ranks ([`crate::ClaimQuality`](../README.md#claimquality) spelling);
  empty for people and for Bookclerk's own processing.
- `value_digest`: Digest of the value (a `chapter_lists` row for chapters).
- `runtime_ms`: Length of the timeline the value was measured on, in milliseconds.
- `input_digest`: For a processed claim, the digest of the value it was derived from.
- `revision`: The subject's claim counter when this claim last changed.
- `pinned_at`: RFC 3339 time an Administrator pinned the claim; `None` when not
  pinned.
- `pinned_by_user_id`: The Administrator who pinned it.
- `created_by_user_id`: The person whose edit the claim is, for a person's edit.
- `updated_at`: RFC 3339 time the claim last changed.
