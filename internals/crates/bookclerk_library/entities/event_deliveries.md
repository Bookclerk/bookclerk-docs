**Fields**

- `id`: Stable delivery id (`{event_id}:{plugin_id}`).
- `event_id`: Parent [`super::domain_events`](domain_events.md) id.
- `plugin_id`: Subscriber plugin id.
- `idempotency_key`: Stable idempotency key independent of attempt/generation.
- `state`: Lifecycle state (`pending`, `running`, `acked`, `rejected`, `dead_letter`).
- `attempt_count`: Number of times a worker has claimed this row (not incremented on resume).
- `max_attempts`: Maximum claims before a failure becomes `dead_letter`.
- `lease_owner`: Worker id that currently holds the lease, when `state = running`.
- `lease_expires_at`: RFC 3339 lease expiry.
- `lease_generation`: Per-claim generation used to fence heartbeat and finalization.
- `run_after`: RFC 3339 time after which a pending delivery may be claimed.
- `invocation_sequence`: Resume ordinal distinct from [`Self::attempt_count`](#model).
- `resume_pending`: `1` when the next claim should resume rather than increment attempt.
- `checkpoint_json`: Bounded checkpoint JSON from `EventResult::Suspended`.
- `checkpoint_schema_version`: Checkpoint schema version.
- `ordering_key`: FIFO key (`book uuid` for `book_acquired`).
- `outcome`: Terminal outcome (`ack`, `reject`, `dead_letter`) when finished.
- `error_message`: Operator-facing error or reject reason.
- `created_at`: RFC 3339 insert time.
- `updated_at`: RFC 3339 last-modified time.
- `cancel_requested`: Cooperative cancel flag (`0` / `1`); running workers check on heartbeat.
- `resource_class`: Concurrency class copied from the catalog (`network` today).
- `wake_event_type`: Event type that can wake this suspended delivery; empty = timestamp-only.
- `wake_filter_json`: Host-owned payload object filter JSON for event-wake; empty = type only.
- `wake_grants_json`: Host-derived wake grants JSON (`schemaVersions` + intersected filter).
- `queue_name`: Queue of the parent event, copied at dispatch.
