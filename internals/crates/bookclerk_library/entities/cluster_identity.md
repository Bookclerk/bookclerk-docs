### Model


Row shape for the singleton `cluster_identity` table.

**Fields**

- `id`: Singleton primary key. Application code inserts `1`.
- `cluster_id`: Stable cluster identifier shared by every host of this database.
- `secret_fingerprint`: SHA-256 hex of the cluster data-encryption key (not the wrapped file).
- `schema_state`: Schema state display recorded when the row was inserted.
- `created_at`: RFC 3339 timestamp when the cluster row was inserted.
