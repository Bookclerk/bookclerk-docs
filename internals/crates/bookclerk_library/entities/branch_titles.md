# bookclerk_library::entities::branch_titles

SeaORM entity for `branch_titles`: on a library, the titles a branch
shared with it (`catalog.sync`; written by `control_plane::branch_catalog`).
Rows name the branch's node and its owner user only; nothing names the
branch's store accounts, users or own branches.

Row shape for one shared title.

**Fields**

- `id`: Surrogate primary key.
- `uuid`: Stable id (an upload's `book_uuid`).
- `provenance`: `node:<node_id>` of the branch that shared it.
- `node_id`: The branch's node id.
- `owner_user_id`: The user who owns the branch's node: the title is theirs here.
- `store`: Store id (`audible`, `libro`, ...).
- `product_id`: Store product id.
- `title`: Display title.
- `authors`: Authors.
- `metadata_json`: The shared metadata (JSON `CatalogMetadata`).
- `primary_key`: Storage key of the primary audio file.
- `pdf_key`: Storage key of the companion PDF.
- `manifest_json`: The shared file manifest (JSON list of `CatalogFile`).
- `manifest_sha256`: Digest of the manifest (`CatalogTitle::manifest_digest`).
- `delivered_sha256`: The manifest digest whose files were delivered, if any.
- `state`: `shared` or `detached`.
- `detached_reason`: Why it was detached: `stopped_sharing`, `left` or `withdrawn`.
- `created_at`: RFC 3339 first share.
- `updated_at`: RFC 3339 last change.
- `seen_at`: RFC 3339 time the branch last named it.
- `delivered_at`: RFC 3339 time its files were delivered.
- `detached_at`: RFC 3339 time it was detached.
