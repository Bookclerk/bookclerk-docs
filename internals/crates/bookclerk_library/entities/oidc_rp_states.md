### Model

```rust
pub struct Model {
    pub id: i64,
    pub state_hash: String,
    pub provider_id: String,

    pub nonce: String,
    pub purpose: String,
    pub user_id: Option<i64>,
    pub expires_at: String,
    pub created_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Surrogate primary key assigned by the database.
- `state_hash`: SHA-256 hex digest of the OAuth `state` parameter.
- `provider_id`: Configured provider id (`corp`, `google`, …).
- `pkce_verifier`: PKCE code_verifier (plaintext; short-lived row).
- `nonce`: OIDC nonce bound to the id_token.
- `purpose`: `login` or `elevate`.
- `user_id`: Owner user id when `purpose = elevate`.
- `expires_at`: RFC 3339 expiry.
- `created_at`: RFC 3339 timestamp when the row was inserted.
