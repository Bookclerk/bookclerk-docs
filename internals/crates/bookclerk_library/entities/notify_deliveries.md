```rust
    pub id: String,

}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Random UUID; the `notify_send` job's payload names it.
- `notification_id`: The notification sent.
- `destination_id`: Where it goes.
- `plugin_instance_id`: Notifier instance that sends it (the destination's, when routed).
- `state`: `pending`, `delivered`, `failed` or `dropped`.
- `attempts`: Send attempts made.
- `provider_id`: The service's id for the delivered message.
- `reason`: Last failure or retry reason, one sanitised line.
- `job_id`: The `notify_send` job enqueued for it; `None` until enqueued.
- `created_at`: RFC 3339 creation time.
- `updated_at`: RFC 3339 time of the last write.
