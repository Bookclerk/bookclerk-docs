Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Message id (UUID).
- `kind`: What it says: `test`, `invite` or `verify_email`.
- `user_id`: The user it is for (the caller, for a test).
- `address`: The address it goes to.
- `plugin_instance_id`: The notifier instance that sends it.
- `state`: `pending`, `delivered`, `failed` or `dropped`.
- `attempts`: Send attempts made.
- `reason`: Why the last attempt failed or why it was dropped.
- `job_id`: The `notify_send` job that sends it, once enqueued.
- `requested_by`: The Administrator who asked for an invite; `None` when the library
  sent it on its own, for other kinds, or once that user is deleted.
- `created_at`: RFC 3339 time it was queued.
- `updated_at`: RFC 3339 time it last changed.
