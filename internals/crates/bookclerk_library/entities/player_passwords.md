# bookclerk_library::entities::player_passwords

### Model

```rust
pub struct Model {
    pub id: String,
    pub user_id: i64,
    pub label: String,
    pub password_hash: String,
    pub created_at: String,
    pub last_used_at: Option<String>,
}
```

Row shape for one player password.

**Fields**

- `id`: Password id (hyphenated UUID).
- `user_id`: The patron it signs in as (`users.id`).
- `label`: The name the patron gave it, such as the app or phone it is for.
- `password_hash`: SHA-256 hex of the password; the password itself is never stored.
- `created_at`: RFC 3339 time it was made.
- `last_used_at`: RFC 3339 time it last signed an app in; null before the first time.
