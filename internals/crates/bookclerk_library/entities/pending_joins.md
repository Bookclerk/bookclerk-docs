# bookclerk_library::entities::pending_joins

SeaORM entity for `pending_joins`: on a host joining a library, one
sign-in in progress (written by `control_plane::create_pending_join`).
The PKCE verifier and the node keys are sealed in `encrypted_secrets`,
never stored here.

### Model

```rust
pub struct Model {
    pub state_hash: String,

    pub expires_at: String,

```

Row shape for one pending join.

**Fields**

- `state_hash`: `hash_token` of the OAuth `state`; the state itself is not stored.
- `owner_origin`: Owner origin (`https://owner.example`), canonical.
- `spki_pin`: SPKI pin the operator confirmed (self-signed owners).
- `owner_cluster_id`: Owner cluster id `GET /api/node/v1/info` reported.
- `library_name`: Library name the owner reported.
- `branch_name`: Name this install asks to join as.
- `redirect_uri`: Redirect URI the authorization was requested with.
- `allow_clerk`: 1 when the operator offered to join as a clerk.
- `created_at`: RFC 3339 creation time.
- `expires_at`: RFC 3339 time after which the row is refused and purged.
