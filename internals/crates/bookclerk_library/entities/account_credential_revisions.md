### Model

```rust
pub struct Model {
    pub plugin_key: String,
    pub account_id: String,
    pub peer: String,
    pub revision: i64,
    pub observed: i64,
    pub updated_at: String,

```

Row shape for one account's revision on one share.

**Fields**

- `plugin_key`: Provenance-qualified PluginKey that owns the account.
- `account_id`: Store account id, unique within its plugin key.
- `peer`: The other instance, as in `account_shares.peer`: `node:<node_id>`
  for the keeper branch whose pushes this library applied,
  `link:<cluster_id>` for a library this keeper pushed to.
- `revision`: The revision that crossed this share: on a library, the newest one
  it applied from its keeper; on a keeper, the newest one it sent.
  Each push a keeper sends carries a higher one than the last.
- `observed`: On a keeper's `link:` row, the fingerprint of the sign-in it last
  pushed ([`crate::control_plane::SignIn::fingerprint`](../control_plane.md#signin)); a different
  one means a new sign-in to send. 0 on a library's rows.
- `updated_at`: RFC 3339 time this row was last written.
