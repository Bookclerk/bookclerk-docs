# bookclerk_library::entities::destination_objects

SeaORM entity for `destination_objects`: the last known state of every
object at each output destination (storage destinations ADR,
`docs/adr/storage-destinations.md`, decision 5).

Written by the destination sync pass from the destination's change feed
and its scheduled listing ([`crate::LibraryStore::record_seen_objects`](../README.md#librarystorerecord_seen_objects),
[`crate::LibraryStore::remove_seen_objects`](../README.md#librarystoreremove_seen_objects),
[`crate::LibraryStore::finish_listing`](../README.md#librarystorefinish_listing)); read by the readers that
act on outside changes, which page the rows changed since a sequence
number ([`crate::LibraryStore::changed_objects`](../README.md#librarystorechanged_objects)).

### Model

```rust
pub struct Model {
    pub destination: String,
    pub object_key: String,
    pub size: i64,
    pub signature: Option<String>,

    pub listed_seq: i64,
    pub changed_seq: i64,
    pub removed: i64,
    pub changed_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `destination`: The destination's plugin instance id.
- `object_key`: The object's key at the destination, as its listing names it.
- `size`: Object size in bytes when last seen.
- `signature`: The backend's opaque change signature (or entity tag) when last
  seen; `None` when the backend gave neither.
- `modified_at_ms`: Last modification time in UTC unix milliseconds, when known.
- `listed_seq`: The destination's change sequence of the last listing or feed page
  that saw the object.
- `changed_seq`: The destination's change sequence when the row last changed (added,
  modified or removed).
- `removed`: 1 once the object is gone (a tombstone kept for readers that page
  changes), else 0.
- `changed_at`: RFC 3339 time the row last changed.
