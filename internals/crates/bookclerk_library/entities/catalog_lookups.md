### Model

```rust
pub struct Model {
    pub node_id: String,
    pub work_id: String,
    pub asked_at: String,
    pub sent_at: Option<String>,
    pub answered_at: Option<String>,
}
```

One question to one branch about one work.

**Fields**

- `node_id`: The branch node asked.
- `work_id`: This library's work the question is about.
- `asked_at`: RFC 3339 time the question was (last) asked.
- `sent_at`: RFC 3339 time it last went out to the branch; `None` while unsent.
- `answered_at`: RFC 3339 time the branch answered; `None` while waiting.
