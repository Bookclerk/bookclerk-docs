### Model

```rust
pub struct Model {
    pub scope_type: String,
    pub scope_id: String,
    pub namespace: String,
    pub parts_id: String,
    pub seq: i64,
    pub body: String,
}
```

One piece of a configuration document too wide for one cell or
statement of the database plugin (`DeriveEntityModel`).

**Fields**

- `scope_type`: Scope kind of the document (`configuration_documents.scope_type`).
- `scope_id`: Scope instance of the document (`configuration_documents.scope_id`).
- `namespace`: Typed domain name of the document (`configuration_documents.namespace`).
- `parts_id`: The set of pieces this one belongs to, unique to the write that
  staged it; a pieced document row's `document_json` names the set to
  read.
- `seq`: The piece's place in the document, from 0.
- `body`: The piece of the document's JSON text, cut on a character boundary.
