```rust
pub struct Model {
    pub plugin_key: String,

    pub grant_json: String,

    pub installed_by: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `plugin_key`: Canonical plugin key.
- `version`: Semver package version.
- `manifest_id`: Manifest id (display alias).
- `manifest_toml`: `plugin.toml` text of the version.
- `settings_json`: JSON `SettingsSchema` the version declares.
- `artifacts_json`: JSON list of per-target artifacts with digests.
- `publisher_verified`: 1 when the publisher was verified at install time.
- `grant_json`: JSON consent grant the operator approved; empty until approved.
- `coordinate`: Package coordinate the version was resolved from (`cargo:…@v`);
  empty for a local archive.
- `installed_at`: RFC 3339 install time.
- `installed_by`: Audit identity of the publisher.
