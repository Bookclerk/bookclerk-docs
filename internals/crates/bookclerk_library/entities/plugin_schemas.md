```rust
    pub recorded_at: String,
    pub recorded_by_node: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `plugin_key`: Canonical plugin key the schema belongs to.
- `manifest_id`: Manifest id (display alias) at pin time.
- `schema_sha256`: SHA-256 of the normalized settings schema (not of the manifest bytes).
- `package_version`: Semver package version that produced the pinned schema.
- `schema_version`: `SettingsSchema` revision stored in `settings_json`.
- `settings_json`: JSON `SettingsSchema` body.
- `recorded_at`: RFC 3339 timestamp of the last pin.
- `recorded_by_node`: Host that recorded the last pin.
