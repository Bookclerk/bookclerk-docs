Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Random id of this holding; a holding removed and added again gets a
  new one, so its `holding_added` event is published again.
- `listing_id`: The listing held.
- `holder`: Stored holder key, `account:<account_id>` or `node:<node_id>`
  (`bookclerk_resolve::Holder::stored`); unique with `listing_id`.
- `holder_kind`: `account` or `node`: which of the typed holder columns is set.
- `plugin_key`: PluginKey of the holding account (the listing's plugin); `None` for a
  node holder.
- `account_id`: Holding store account, with `plugin_key` a foreign key into
  `accounts`; `None` for a node holder.
- `node_id`: Holding branch library node (`nodes.node_id`); `None` for an account
  holder.
- `entitlement`: `purchase`, `plus`, `loan` or `free`.
- `purchased_at`: RFC 3339 time it was bought or added, when known.
- `seen_pass`: Id of the scan pass that last listed this holding
  (`account_scan_state.pass_id`); `None` until a pass lists it.
- `created_at`: RFC 3339 timestamp when the row was inserted.
- `updated_at`: RFC 3339 timestamp when the row was last modified.
