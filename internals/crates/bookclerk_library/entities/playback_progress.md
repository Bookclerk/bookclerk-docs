### Model

```rust
pub struct Model {
    pub user_id: i64,
    pub edition_id: String,
    pub position_ms: i64,
    pub duration_ms: Option<i64>,
    pub is_finished: i64,
    pub started_at: String,
    pub finished_at: Option<String>,
    pub updated_at: String,
}
```

Row shape for one person's position in one edition.

**Fields**

- `user_id`: The listener (`users.id`).
- `edition_id`: The edition (`editions.id`) the position is in.
- `position_ms`: Position on the edition's timeline, in milliseconds from its start.
- `duration_ms`: The edition's whole runtime in milliseconds as the last player
  reported it; `None` until one has.
- `is_finished`: `1` once the person reached the end of this edition, else `0`.
- `started_at`: RFC 3339 time the person first played the edition.
- `finished_at`: RFC 3339 time the person last reached the end; `None` until then.
- `updated_at`: RFC 3339 time of the last write; orders Continue listening.
