```rust
    pub id: String,

}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Random UUID; the `destinationId` the notifier sees.
- `plugin_instance_id`: Notifier plugin instance that sends to this destination.
- `kind`: `channel` or `personal`.
- `user_id`: Patron who owns a personal destination; `None` for a channel.
- `label`: Name shown to administrators or the patron; never a secret.
- `address_json`: Canonical address document of a personal destination; empty for a
  channel. May hold secrets, so it is never logged.
- `failure_count`: Permanent send failures since the last delivery.
- `paused_at`: RFC 3339 time the destination was paused; `None` while active.
- `paused_reason`: Why it was paused (the last failure reason).
- `created_at`: RFC 3339 creation time.
- `updated_at`: RFC 3339 time of the last write.
