## Structs

### Model

```rust
pub struct Model {
    pub destination: String,
    pub storage_key: String,
    pub library_id: String,
    pub title_ref: String,
    pub writer: String,
    pub state: String,
    pub replaced: i64,
    pub written_at: String,
}
```

One copied file on one of this install's destinations.

**Fields**

- `destination`: This install's destination id (`local`, `s3`).
- `storage_key`: The file's storage key on that destination.
- `library_id`: The library the title was acquired for.
- `title_ref`: The title the file belongs to: its call number on that library (its
  edition), else its holding id there.
- `writer`: The copy attempt that wrote it last: `<node id>/<process
  incarnation>/<attempt id>`.
- `state`: `copying` while the attempt runs, `kept` once the library committed
  the title.
- `replaced`: 1 when the attempt took over a kept copy of the same title, so a
  failed attempt leaves the file and the record kept.
- `written_at`: RFC 3339 time of the latest write.
