# bookclerk_library::entities::library_work_rows

SeaORM entity for `library_work_rows`: the library's page index.

One row per held top-level work, refreshed from the library model by
[`crate::LibraryStore::refresh_library_works`](../README.md#librarystorerefresh_library_works), so list views page one
table instead of joining works, editions, listings and holdings.

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `work_id`: The work (`works.id`); a top-level work, never a podcast episode.
- `kind`: Work kind (`WorkKind::as_str`): `book` or `podcast`.
- `title`: The work's display title.
- `sort_title`: Sort key of the title: lower case, a leading article dropped.
- `authors`: Authors (or a show's hosts) joined for display, in billing order.
- `sort_author`: Sort key of the first author; empty when the work names none.
- `series`: Name of the first series the work belongs to.
- `series_position`: The work's position in [`Self::series`](#model), as the store wrote it.
- `cover_edition_id`: The edition whose cover the list shows (`editions.id`).
- `media_kinds`: Sorted, comma-joined media kinds of the work's editions
  (`MediaKind::as_str`), such as `audio,ebook`.
- `acquire_status`: The furthest acquire state any edition of the work reached
  (`AcquireStatus::as_str`).
- `edition_count`: How many editions the work has.
- `holding_count`: How many holdings (account or node) the work's listings have.
- `added_at`: RFC 3339 timestamp of the work's newest holding, for "recently
  added".
- `sort_series`: Sort key of the series order: `0`, the lower-cased first series
  name, a separator and the zero-padded position; `1` when the work is
  in no series, so those sort last.
- `length_minutes`: Runtime in minutes of the work's longest held edition; 0 when no
  store reported one.
- `purchased_at`: RFC 3339 timestamp of the newest purchase a store reported for the
  work's holdings; empty when none did.
- `refreshed_at`: RFC 3339 timestamp at which the refresh that wrote this row read the
  model; a refresh that read earlier never overwrites it.
- `facets_ready`: 1 once every `library_work_facets` row of the refresh that wrote
  this row is in place, 0 while they are being replaced. A patron
  scope admits only rows at 1.
