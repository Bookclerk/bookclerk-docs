### Model

```rust
pub struct Model {
    pub plugin_key: String,
    pub account_id: String,
    pub sync_token: String,
    pub resume_cursor: String,
    pub resume_token: String,
    pub last_complete_at: Option<String>,
    pub pass_id: String,
    pub updated_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `plugin_key`: Provenance-qualified PluginKey that owns the account.
- `account_id`: Store account id, unique within one plugin key.
- `sync_token`: Opaque token the plugin returned at the end of the last pass; empty
  asks the next pass to be full.
- `resume_cursor`: Cursor of the next page of a pass that stopped part way; empty when no
  pass is in progress.
- `resume_token`: Sync token the in-progress pass started with (sent again on resume).
- `last_complete_at`: RFC 3339 time the last complete (full) pass ended; `None` before one.
- `pass_id`: Id of the pass in progress or last run; each written page stamps it
  on the holdings it listed (`holdings.seen_pass`). Empty before the
  first pass.
- `updated_at`: RFC 3339 time of the last write (a resume cursor's age).
