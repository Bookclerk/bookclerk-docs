### Model

```rust
pub struct Model {
    pub token_hash: String,
    pub session_id: i64,
    pub kind: String,
    pub expires_at: String,
}
```

Row shape for one token.

**Fields**

- `token_hash`: SHA-256 hex of the token; the token itself is never stored.
- `session_id`: The card's `portal_sessions.id`.
- `kind`: `access` (one hour, sent on every request) or `refresh` (thirty
  days, traded for a new pair).
- `expires_at`: RFC 3339 time it stops working.
