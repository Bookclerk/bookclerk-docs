Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Singleton id; always `1`.
- `retries_total`: Persisted `retry` outcomes (including reclaim-as-retry).
- `suspensions_total`: Persisted `suspended` outcomes.
- `dead_letters_total`: Transitions into `dead_letter`.
- `dispatch_latency_ms_sum`: Sum of first-dispatch latencies in milliseconds.
- `dispatch_count`: Number of first-dispatch samples.
- `handler_latency_ms_sum`: Sum of `onEvent` handler durations in milliseconds.
- `handler_count`: Number of handler-duration samples.
