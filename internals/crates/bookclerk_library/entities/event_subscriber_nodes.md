**Fields**

- `node_id`: Daemon node id (primary key part; files-dir UUID).
- `plugin_id`: Subscriber plugin identity (canonical PluginKey).
- `subscriptions_json`: JSON array of catalog subscriptions (`type`, `schema_versions`, …).
- `enabled`: `1` when this node wants matching deliveries for `plugin_id`.
- `heartbeat_at`: RFC 3339 last heartbeat from this node.
