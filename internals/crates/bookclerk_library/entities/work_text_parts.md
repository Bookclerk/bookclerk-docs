### Model

```rust
pub struct Model {
    pub work_id: String,
    pub version: String,
    pub field: String,
    pub seq: i64,
    pub parts: i64,
    pub body: String,
}
```

One piece of a work's text too wide for its row on the database plugin
(`DeriveEntityModel`).

**Fields**

- `work_id`: The work the text belongs to (`works.id`).
- `version`: The write this piece belongs to; `works.text_version` names the one
  to read.
- `field`: Which text it is: `description`, `subjects` or `categories`.
- `seq`: The piece's place in the text, from 0.
- `parts`: How many pieces the text has; the same on every piece of it.
- `body`: The piece of the text, cut on a character boundary.
