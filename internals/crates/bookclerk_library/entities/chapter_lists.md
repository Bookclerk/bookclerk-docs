Row shape for one stored chapter list.

**Fields**

- `digest`: Lower-case hex SHA-256 of the list's canonical encoding.
- `chapter_count`: How many entries the list has (`chapter_list_entries` rows).
- `created_at`: RFC 3339 time the list was first stored.
