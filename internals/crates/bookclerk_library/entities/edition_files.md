# bookclerk_library::entities::edition_files

SeaORM entity for `edition_files`: every file key an acquire or a host
upload wrote, per output destination, and the edition it belongs to
(library data model ADR, `docs/adr/library-data-model.md`,
section 3). Written by the acquire pipeline
([`crate::LibraryStore::record_edition_file`](../README.md#librarystorerecord_edition_file)) and by
`control_plane::uploads`, which refuses an upload a key another edition
holds and deletes an aborted upload's copy only while the key is still
its own.

### Model

```rust
pub struct Model {
    pub destination: String,
    pub storage_key: String,
    pub owner_kind: String,
    pub owner_id: String,
    pub role: String,
    pub lossless: i64,
    pub bitrate_kbps: Option<i64>,
    pub sha256: Option<String>,
    pub writer: String,
    pub written_at: String,
}
```

Row shape for one recorded file key.

**Fields**

- `destination`: Output destination id (`local`, `s3`).
- `storage_key`: Storage key on that destination.
- `owner_kind`: `edition`: files belong to editions.
- `owner_id`: The edition id.
- `role`: What the file is ([`crate::FileRole`](../README.md#filerole)).
- `lossless`: 1 for a lossless audio encoding; 0 otherwise or unknown (an integer,
  as every flag column is, so each database adapter decodes it alike).
- `bitrate_kbps`: Audio bitrate in kilobits per second, when known.
- `sha256`: Lowercase hex SHA-256 of the content, when known (host uploads).
- `writer`: The host upload id that claimed the key last, or
  [`crate::store::ACQUIRE_WRITER`](../README.md#acquire_writer) for an acquire run on this node.
- `written_at`: RFC 3339 time of the latest claim.
