# bookclerk_library::entities::link_imports

SeaORM entity for `link_imports`: on a branch, the branch owner's books
acquired for a library it joined and imported into this library as well
(written by `control_plane::link_imports`). The catalog sync never sends
a library a book recorded here for it.

### Model

```rust
pub struct Model {
    pub id: i64,
    pub cluster_id: String,
    pub plugin_key: String,
    pub account_id: String,
    pub marketplace: String,
    pub product_id: String,
    pub created_at: String,
}
```

One imported book, for one library.

**Fields**

- `id`: Surrogate primary key; the keyset the catalog sync pages by.
- `cluster_id`: The library the book was acquired for.
- `plugin_key`: Provenance-qualified plugin key of the store.
- `account_id`: Store account that holds the book.
- `marketplace`: Store marketplace, as `store_listings` stores it.
- `product_id`: Store product id, as `store_listings` stores it.
- `created_at`: RFC 3339 time of the first import from that library.
