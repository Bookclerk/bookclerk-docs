The stored taste ranking of one entry of the shared request queue
(`DeriveEntityModel`).

The row holds only what the ranking job computed. Titles, covers, wish
counts and wishers stay on the open `title_requests` rows and are joined
when the queue is read, so a new wish shows at once and nothing here
copies catalog metadata.

**Fields**

- `work_id`: The work (`works.id`) the entry's wishes are for; one row per work.
- `owned`: 1 when the library already holds the entry's work, so the queue hides it.
- `taste_score`: Household taste score of the entry before the wish-count boost
  (finite; 0 when nothing in the library matches it).
- `reasons_json`: Taste reasons as a JSON array of strings; wish-count reasons are added at read time.
- `ranked_at`: RFC 3339 timestamp of the ranking pass that wrote the row.
