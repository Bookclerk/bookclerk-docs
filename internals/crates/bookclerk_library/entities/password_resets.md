### Model

```rust
pub struct Model {
    pub token_hash: String,
    pub user_id: i64,
    pub email: String,
    pub expires_at: String,
    pub created_at: String,
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `token_hash`: SHA-256 hex digest of the link's token (the token is never stored).
- `user_id`: The user whose password it resets; one live link per user.
- `email`: The verified address the link was sent to; it works only while the
  user still has it, verified.
- `expires_at`: RFC 3339 time the link stops working.
- `created_at`: RFC 3339 time it was made.
