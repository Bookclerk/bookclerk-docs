# bookclerk_library::entities::destination_feeds

SeaORM entity for `destination_feeds`: how each output destination's
outside changes are followed, and how healthy that is (storage
destinations ADR, `docs/adr/storage-destinations.md`, decision 5).

One row per destination, written by the destination sync pass that
holds the destination's lease ([`crate::LibraryStore::save_destination_feed`](../README.md#librarystoresave_destination_feed))
and read for its next pass and for the destination's health in Settings.

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `destination`: The destination's plugin instance id.
- `seq`: The last change sequence number handed out for this destination.
- `feed_state`: The change feed's state (`FeedState::as_str`): `off`, `healthy`,
  `gap` or `failing`.
- `feed_cursor`: The feed cursor to read from next; `None` before the first read.
- `feed_error`: The last feed failure, for operators.
- `feed_checked_at`: RFC 3339 time the feed was last read.
- `listing_seq`: Sequence of the listing in progress; `None` between listings.
- `listing_cursor`: Cursor of the next page of the listing in progress.
- `listing_started_at`: RFC 3339 time the listing in progress (or the last one) started.
- `listed_at`: RFC 3339 time the last listing finished.
- `next_listing_at`: RFC 3339 time the next scheduled listing is due.
- `listing_error`: Why the last listing failed or was not applied, for operators.
- `objects`: Objects the destination held at the end of the last listing or feed
  page.
- `checked_seq`: The last sequence the copy check has read changes up to.
- `listing_base`: Objects known when the listing in progress started, which its
  removal guard is judged against; `None` between listings.
- `revision`: Write count of this row: each save names the revision it read and
  fails when another writer saved since (a sync pass whose lease
  another node took).
- `updated_at`: RFC 3339 time the row was last written.
