### Model

```rust
pub struct Model {
    pub owner_cluster_id: String,
    pub store: String,
    pub marketplace: String,
    pub product_id: String,
    pub version: String,
    pub seq: i64,
    pub body: String,
}
```

One piece of a window book's JSON, at most the database's cell limit.

**Fields**

- `owner_cluster_id`: The library (owner cluster id) that holds the book.
- `store`: The store's plain id (`audible`, `libro`, ...).
- `marketplace`: Lower-cased store marketplace; empty when the store has none.
- `product_id`: The store's product id.
- `version`: The write that added it (random); the book row names the version
  to read.
- `seq`: The piece's place, from 0; the pieces joined in this order are the
  whole JSON.
- `body`: This piece of the JSON text.
