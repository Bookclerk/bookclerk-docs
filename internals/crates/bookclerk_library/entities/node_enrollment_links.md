Row shape for one enrollment link.

**Fields**

- `link_id`: Public link id (the second field of `bcn1.<link_id>.<secret>`).
- `token_hash`: `hash_token(secret)`. The secret itself is never stored.
- `for_user_id`: User who will own the enrolled node.
- `label`: Free-form label shown in listings.
- `created_by`: Audit id of the minter (`operator:<id>` or `user:<id>`).
- `created_at`: RFC 3339 mint time.
- `expires_at`: RFC 3339 expiry.
- `redeemed_at`: RFC 3339 redeem time, once redeemed.
- `redeemed_node_id`: Node the redeem created.
- `revoked_at`: RFC 3339 revoke time, once revoked.
