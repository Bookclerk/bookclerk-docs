# bookclerk_library::entities::playback_sessions

SeaORM entity for `playback_sessions`: one stretch of listening by one
person on one player. A session is also the leave to stream the
edition's files from one destination, checked afresh on every request
(`control_plane::copies::authorize_playback`).

Row shape for one play session.

**Fields**

- `id`: Session id (hyphenated UUID).
- `user_id`: The listener (`users.id`).
- `edition_id`: The edition (`editions.id`) being played.
- `serving_node_id`: The node that opened the session and streams its files.
- `destination`: The output destination the files are read from.
- `files_digest`: Digest of the edition's file rows on that destination when the
  session opened; a stream request is refused once they differ.
- `client_kind`: What kind of player opened it ([`crate::PlayerKind`](../README.md#playerkind)).
- `client_name`: The player's own name for itself, shown in listening history.
- `start_position_ms`: Position the session started from, in milliseconds.
- `position_ms`: Position at the last sync, in milliseconds.
- `listened_ms`: Time spent listening in this session, in milliseconds of wall
  clock as the player counted it.
- `started_at`: RFC 3339 time the session opened.
- `updated_at`: RFC 3339 time of the last sync.
- `closed_at`: RFC 3339 time the player closed the session; `None` while open.
