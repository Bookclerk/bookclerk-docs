## Structs

### Model

```rust
pub struct Model {
    pub id: String,
    pub user_id: i64,
    pub edition_id: String,
    pub position_ms: i64,
    pub title: String,
    pub created_at: String,
    pub updated_at: String,
}
```

Row shape for one bookmark.

**Fields**

- `id`: Bookmark id (hyphenated UUID).
- `user_id`: The person who made it (`users.id`).
- `edition_id`: The edition (`editions.id`) it marks a place in.
- `position_ms`: The marked place, in milliseconds from the edition's start.
- `title`: The person's note for it; may be empty.
- `created_at`: RFC 3339 time it was made.
- `updated_at`: RFC 3339 time of the last change.
