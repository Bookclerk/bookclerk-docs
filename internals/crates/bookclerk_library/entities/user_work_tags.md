# bookclerk_library::entities::user_work_tags

SeaORM entity for `user_work_tags`: one user's tags on a work, one row
per tag.

Written with `user_title_state.tags` by
[`crate::LibraryStore::set_user_title_state`](../README.md#librarystoreset_user_title_state), so the library page can
filter by a tag.
