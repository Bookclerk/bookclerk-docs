### Model

```rust
pub struct Model {

    pub source_kind: String,

    pub runtime_ms: Option<i64>,
    pub revision: i64,
    pub updated_at: String,
}
```

Row shape for one edition's resolved chapters.

**Fields**

- `edition_id`: The edition (`editions.id`).
- `digest`: The winning claim's list (`chapter_lists.digest`).
- `source_kind`: The winning claim's source kind ([`crate::ChapterSourceKind`](../README.md#chaptersourcekind)).
- `source_id`: The winning claim's source id.
- `runtime_ms`: Length of the timeline the list was measured on, in milliseconds.
- `revision`: The highest claim revision the resolution read.
- `updated_at`: RFC 3339 time of the last change.
