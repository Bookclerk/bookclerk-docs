```rust
}
```

Row shape for this table (`DeriveEntityModel`).

**Fields**

- `plugin_key`: Provenance-qualified PluginKey that owns the account.
- `account_id`: Store account id, unique within one plugin key.
- `pace_mode`: `default`, `custom` or `unlimited` ([`crate::pacing::PaceOverride`](../pacing.md#paceoverride)).
- `downloads_per_day`: Custom downloads per rolling 24 hours; `None` keeps the storefront's.
- `min_gap_seconds`: Custom seconds between downloads; `None` keeps the storefront's.
- `cooldown_until_ms`: End of the store's cool-down in Unix milliseconds; `None` for none.
- `updated_at`: RFC 3339 time of the last write.
