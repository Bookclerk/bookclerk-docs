Row shape for this table (`DeriveEntityModel`).

**Fields**

- `id`: Random row id (UUID).
- `plugin_key`: Provenance-qualified PluginKey that owns the account.
- `account_id`: Store account id, unique within one plugin key.
- `started_at_ms`: When the download started, in Unix milliseconds.
- `job_id`: The acquire job that ran it, when one did.
- `paced`: 1 when the host started the download itself, 0 when a person did.
